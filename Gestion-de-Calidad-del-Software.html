de calidad

Conocé los conceptos, métricas y estándares que permiten comprender y evaluar la calidad del software.

01 - conceptos

¿Que es la Calidad del Software?

La calidad del software se relaciona con su capacidad para cumplir los requisitos establecidos, funcionar correctamente y satisfacer las necesidades de sus usuarios.

La calidad no depende solamente del producto final. También está relacionada con la forma en que se desarrolla, se prueba y se mejora el software.

El material de Scrum destaca la relación entre los procesos y la calidad del resultado, y también señala la importancia del conocimiento y la experiencia de las personas que participan en el desarrollo

02 - Caracteristicas

Características de la Calidad

Estas características sirven como forma sencilla de explicar los aspectos que se evalúan al hablar de calidad

Funcionalidad

Acceso a los conceptos centrales de calidad aplicados al software.

Evalúa si el software cumple con las funciones necesarias para satisfacer las necesidades del usuario.

Fiabilidad

Una entrada a los procesos tradicionales y ágiles de desarrollo.

Indica la capacidad del software para funcionar correctamente y mantener un comportamiento estable durante su utilización.

Usabilidad

Un acceso inicial a metodologías relevantes para equipos ágiles.

Se relaciona con la facilidad con la que los usuarios pueden comprender, aprender y utilizar el software.

Eficiencia

Un acceso inicial a metodologías relevantes para equipos ágiles.

Evalúa el rendimiento del software y la cantidad de recursos que utiliza para realizar sus funciones.

03 - Medición

Metricas de Calidad

Las métricas permiten medir diferentes aspectos de la calidad de un software para conocer su comportamiento y detectar posibles problemas.

Rendimiento

Cómo responde el sistema y cuánto tarda en realizar operaciones.

Evalúa la velocidad de respuesta del software, el tiempo que necesita para realizar una tarea y la cantidad de recursos que utiliza.

Fiabilidad

Frecuencia de errores o fallos del sistema.

Indica la capacidad del software para funcionar correctamente durante un período determinado sin presentar fallos.

Usabilidad

Qué tan fácil resulta utilizar el software.

Se relaciona con la facilidad para aprender, comprender y utilizar el software de manera sencilla y eficiente.

Mantenibilidad

Qué tan fácil es modificar o corregir el software.

Evalúa qué tan sencillo resulta encontrar errores, realizar cambios y adaptar el software a nuevas necesidades.

La familia SQuaRE incluye estándares específicos relacionados con la medición de la calidad de productos de software.

04 - Desarrollo

Calidad en el desarrollo de Ágil

Cómo se construye calidad mientras se desarrolla, según el material de Scrum.

Mejora Continua

El desarrollo ágil busca revisar constantemente el trabajo realizado para detectar problemas y realizar mejoras. En Scrum, las iteraciones permiten analizar el producto y la forma de trabajo para decidir qué mantener, modificar o mejorar.

Pruebas

Una forma de prevenir errores es utilizar pruebas durante el desarrollo. El material presenta TDD (Test Driven Development), donde primero se desarrollan las pruebas que debe superar el código y después se desarrolla el código correspondiente.

Calidad de Producto

En Scrum, la calidad también se relaciona con el conocimiento, la experiencia y la creatividad de las personas que forman parte del equipo.

ISO/IEC 9126 actualmente está retirada y fue reemplazada por los estándares de la familia ISO/IEC 25000 (SQuaRE), incluyendo ISO/IEC 25010. El nuevo modelo incorpora Seguridad y Compatibilidad como características principales, además de la eficiencia en el desempeño.
